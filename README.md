# ProcureMind
### AI-Powered Procurement Anomaly Detector for Enterprise Spend

ProcureMind is an AI-powered enterprise procurement intelligence platform that detects anomalous purchase orders and invoices using Machine Learning and Explainable AI (XAI). The system helps organizations identify procurement risks, support investigation workflows, and improve procurement decision-making through interactive dashboards and analytical reporting.

---

## Features

- AI-based procurement anomaly detection
- Duplicate invoice detection
- Unusual spending pattern detection
- Pricing inconsistency detection
- Suspicious vendor transaction detection
- Explainable AI (SHAP) for model transparency
- Human review and investigation workflow
- Procurement analytics dashboard
- Risk scoring and follow-up recommendations
- Report generation and cost savings analysis
